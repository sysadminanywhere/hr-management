**HCM** — это современная enterprise-платформа для автоматизации HR-процессов, разработанная специально для развертывания в **закрытом контуре компании (On-Premise)**. Полный контроль над персональными данными сотрудников (соответствие ФЗ-152), независимость от зарубежных облачных SaaS-сервисов и моментальный запуск.

[Официальный сайт проекта](https://hcm.ria-media.net)

## 🚀 Ключевые возможности

*   **Учет сотрудников и кадровый контур:** ведение личных карточек, истории изменений, должностей.
*   **Визуальная оргструктура:** интерактивная схема компании, отделов и подчиненности в реальном времени.
*   **Управление отсутствиями:** автоматизация графиков отпусков, согласование больничных и отгулов.
*   **Диагностика системы:** встроенный модуль мониторинга базы данных, файлового хранилища и фоновых задач администратора.
*   **100% On-Premise:** данные не уходят во внешние облака. Полная изоляция контура.

## ⚡ Быстрый старт (Развертывание за 2 минуты)

Система полностью упакована в Docker-контейнеры и готова к запуску одной командой. Образы скачиваются напрямую из публичного Docker Hub.

### 1. Подготовка окружения
Создайте файл `.env` в рабочей директории и добавьте обязательные параметры конфигурации:

```env
POSTGRES_DB=hcm
POSTGRES_USER=hcm
POSTGRES_PASSWORD=придумайте_надежный_пароль_базы

HCM_ADMIN_USERNAME=admin
HCM_ADMIN_PASSWORD=придумайте_пароль_администратора

HCM_BACKEND_IMAGE=sysadminanywhere/hcm-backend:latest
HCM_FRONTEND_IMAGE=sysadminanywhere/hcm-frontend:latest
```
> ⚠️ **Важно:** Замените значения по умолчанию на свои собственные пароли. Не передавайте файл `.env` третьим лицам.

### 2. Запуск контейнеров
Убедитесь, что у вас установлены Docker и Docker Desktop / Engine с поддержкой Compose. Выполните команду проверки конфигурации и старта:

```bash
docker compose config --quiet && docker compose up -d --wait
```

### 3. Первый вход
Откройте в браузере адрес `http://localhost` (или настроенный вами домен).
*   Используйте логин и пароль администратора (`HCM_ADMIN_USERNAME` и `HCM_ADMIN_PASSWORD`), которые вы указали в файле `.env`.
*   При первом запуске автоматически активируется **trial-период на 30 дней**.

## 🛡 Эксплуатация и Безопасность

*   **Резервное копирование:** Перед загрузкой реальных данных настройте регулярный бэкап базы данных PostgreSQL и разделов файлового хранилища.
*   **Обновления:** Перед обновлением образов обязательно сделайте резервную копию данных, после чего выполните команду `docker compose pull`. Состояние миграций можно отслеживать в панели «Диагностика».
*   **Логирование:** В случае проблем со стартом backend-модуля, используйте стандартную команду: `docker compose logs backend`.
